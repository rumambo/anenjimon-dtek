# anenjimon-dtek — ретранслятор городских данных Киева для AnenjiMon

Открытые данные Киева в исходном виде роутеру не по силам. API обращений в Контактный центр
**1551** отдаёт только целый месяц одним JSON (до ~100 МБ), без фильтров, сжатия и ETag.
Поэтому GitHub Actions раз в 30 минут скачивает месяц, оставляет нужное и раскладывает по улицам.
[AnenjiMon](https://github.com/rumambo/anenjimon) забирает только файл своей улицы — десятки килобайт.

Аварийные отключения **ДТЭК** собираются отдельным воркфлоу через headless-браузер Playwright
раз в 10 минут по 8 улицам массива (Північно-Броварський) и также публикуются в компактном JSON.

Данные лежат в ветке **`data`**. Это одна коммит-«фотография» без истории, ветка не растёт.
Прямые ссылки:

```
https://raw.githubusercontent.com/rumambo/anenjimon-dtek/data/1551/meta.json
https://raw.githubusercontent.com/rumambo/anenjimon-dtek/data/1551/index.json
https://raw.githubusercontent.com/rumambo/anenjimon-dtek/data/1551/areas/pivnichno-brovarskyi-recent.json
https://raw.githubusercontent.com/rumambo/anenjimon-dtek/data/1551/areas/pivnichno-brovarskyi.json
https://raw.githubusercontent.com/rumambo/anenjimon-dtek/data/1551/streets/vul-andriia-malyshka.json
https://raw.githubusercontent.com/rumambo/anenjimon-dtek/data/1551/city.json
https://raw.githubusercontent.com/rumambo/anenjimon-dtek/data/buvets/buvets.json
https://raw.githubusercontent.com/rumambo/anenjimon-dtek/data/dtek/areas/pivnichno-brovarskyi.json
https://raw.githubusercontent.com/rumambo/anenjimon-dtek/data/dtek/active_emergencies.json
https://raw.githubusercontent.com/rumambo/anenjimon-dtek/data/dtek/latest.json
https://raw.githubusercontent.com/rumambo/anenjimon-dtek/data/dtek/status.json
```

raw.githubusercontent.com отдаёт `ETag`: запрос с `If-None-Match` получает `304` без тела,
если файл не менялся. Файл улицы меняется, только когда по ней появилось новое обращение
или старое выпало из окна.

| Бюветы | [Бюветні комплекси… (Київводфонд)](https://data.gov.ua/dataset/a4144c44-aabe-4e49-8ea4-b79b0b8ebdcc) | у источника раз в квартал; мы — каждый запуск |

## ДТЭК (аварии по массиву)

Сборщик `relay/dtek.py` опрашивает ДТЭК Киевские электросети по 8 улицам Північно-Броварського масива
(список в `relay/areas.json`):

* `dtek/areas/pivnichno-brovarskyi.json` — аварийные отключения массива, список домов и статус
* `dtek/active_emergencies.json` — массив только активных аварий (пустой `[]`, если аварий нет)
* `dtek/latest.json` — полный срез по всем 8 улицам со всеми домами
* `dtek/status.json` — компактный статус (`OK` или `EMERGENCY`)

## Что берём из 1551

Только Київ и категории (код → категория 1551):

| Код | Категория |
|---|---|
| `cold` | Холодне водопостачання (в т.ч. «Відсутній тиск ХВП з 10-го поверху включно» / «…до 9-го») |
| `hot` | Гаряче водопостачання |
| `heat` | Опалення |
| `power` | Електропостачання (відсутність, стабілізаційне відключення, коливання напруги…) |
| `lift` | Ліфт |
| `gas` | Газифікація |
| `buvet` | Робота бюветів |
| `light` | Освітлення приміщень (під'їзд) |
| `pipes` | Порив труб у будинку, витік холодної води / каналізації на поверхню |

Одно обращение приходит строкой на каждого исполнителя (ЖЕД, РЕМ, водоканал…) — дубли убираются по `uid`.
Квартир и личных данных в источнике нет. Время закрытия обращения источник не даёт.
Время `t` — как в источнике, с суффиксом `Z`.

## Формат 1551

**`1551/meta.json`** — свежесть и счётчики. `generated` — когда собрано; `source_latest` — самая свежая
запись источника; `lag_minutes` — разница между ними; `window_days`; `kinds` — сколько записей
каждой категории в окне; `months` — сколько записей в месячных архивах.

**`1551/index.json`** — `{"streets":[{"name","file","n","last","kinds"}]}`. `name` — как в 1551
(«вул. Андрія Малишка», «просп. Берестейський (Перемоги)»). `file` — путь от `1551/`.
Имя файла — транслитерация; при совпадении добавляется `-2`, `-3`. Улицу ищите по `name`,
а не вычисляйте имя файла сами.

**`1551/streets/<slug>.json`** — обращения по улице за 31 день, новые сверху:

```json
{"street":"вул. Андрія Малишка","items":[
  {"t":"2026-11-04T12:08Z","k":"cold","c":"Відсутність ХВП","h":"21-А"},
  {"t":"2026-11-04T08:26Z","k":"lift","c":"Не працює пасажирський ліфт","h":"31"}]}
```
`k` — код категории, `c` — подкатегория 1551, `h` — дом (может быть `null`), `b` — корпус (если есть).

**`1551/areas/<slug>.json`** — все улицы массива одним файлом за 31 день (~180 КБ),
и **`1551/areas/<slug>-recent.json`** — то же за последние 48 часов (~30 КБ, для опроса раз в 30 минут).
Массивы задаются в [`relay/areas.json`](relay/areas.json): `{slug: {title, streets: [названия]}}`.
Названия пишутся как в боте соседей («вул. Малишка Андрія», «бул. Дарницький»). Улица 1551 подходит,
если в ней есть все слова названия — в любом порядке, без учёта регистра, апострофов и типа улицы
(вул./бул./бульв./просп./…). Так «вул. Малишка Андрія» находит «вул. Андрія Малишка», «вул. Солов’яненка Анатолія» —
«вул. Солов’яненка Анатолія (Бойченка Олександра)», а «бул. Дарницький» не цепляет «вул. Ново-Дарницька».
AnenjiMon может сопоставлять свои улицы тем же правилом (`street_matches` в `relay/city1551.py`).

```json
{"area":"pivnichno-brovarskyi","title":"Північно-Броварський масив","hours":48,
 "streets":[{"name":"бульв. Дарницький","pattern":"бул. Дарницький","file":"streets/bulv-darnytskyi.json"}, …],
 "items":[{"t":"2026-11-04T17:18Z","k":"power","c":"Відсутність електропостачання","h":"1","s":"бульв. Дарницький"}, …]}
```
`s` — улица записи в написании 1551, `pattern` — название из `areas.json`. В шапке ещё `source_latest`
(самая свежая запись 1551) и `buvets` — до 5 рабочих бюветов массива: сначала на его улицах, потом в радиусе
1,5 км от центра (центр — `center: [lat, lon]` в `areas.json` или середина бюветов на улицах массива); поля
`street`, `house`, `lat`, `lon`, `generator`, `on_street`, `km` (от центра), `complaints_7d`. Сейчас массив один —
Північно-Броварський, те же 8 улиц, что в боте соседей. Если по какой-то улице за окно
не было ни одного обращения, она попадает в `meta.areas.<slug>.unmatched`.

**`1551/city.json`** — по городу: `daily` (по дням по киевскому времени × категории),
`hourly` (последние 48 ч), `hot` (улицы, где за последние 6 ч не меньше 3 обращений одной категории,
со списком домов), `kinds` (названия категорий по-украински).

**`1551/months/ГГГГ-ММ.json.gz`** — отфильтрованный архив месяца (13 месяцев). Нужен, чтобы
окно 31 день переходило через границу месяца без повторной загрузки прошлого месяца.

**`buvets/buvets.json`** — `items`: `street`, `house`, `district`, `lat`, `lon`, `works`,
`generator` (работает без света), `depth_m`, `analysis` (ссылка на анализ воды),
`complaints_7d` — жалобы «Не працює бювет» в 1551 за 7 дней по этому адресу.

## Защита от сломанного источника

- Если в текущем месяце записей стало вдвое меньше, чем в прошлый запуск, или их нет вовсе
  (кроме 1-го числа), запуск падает, и ветка `data` остаётся прежней. GitHub пришлёт письмо о падении.
- Если CSV бюветов недоступен или в нём меньше 50 строк, остаётся прошлый список.
- Повторный запуск на тех же данных даёт те же байты (gzip без времени), поэтому меняется только `meta.json`.
- В первые 2 дня месяца прошлый месяц перекачивается — источник дописывает поздние записи.

## Что проверять в AnenjiMon

- `meta.generated` старше 3 часов — ретранслятор не работает (или GitHub отключил расписание).
- `meta.lag_minutes` больше 360 — источник 1551 застрял.

## Запуск локально

```sh
python3 -m unittest discover -s relay -v
python3 relay/city1551.py --out out                      # живые данные 1551
python3 relay/dtek.py --out out                          # аварии ДТЭК
```

## Расписание

* `.github/workflows/city1551.yml` — в :17 и :47 каждого часа.
* `.github/workflows/dtek.yml` — раз в 10 минут (`*/10 * * * *`).

GitHub может задерживать запуски по расписанию на 5–20 минут.
Последний шаг каждого воркфлоу «включает» расписание через API, чтобы GitHub не отключил его
после 60 дней без коммитов.
